# One registration. Two ways to see it.

An interactive portfolio case study: how a study-abroad agency replaced a
5-hour, email-driven **registration → review → payment** process with a
self-serve flow.

**▶ Live demo:** https://ningweiyun-hub.github.io/casestudy/

Two ways to explore, from the opening screen:

- **Hands-on** — play both roles. Submit a registration as the corporate
  client, then switch and approve it as the reviewer. Three walls are staged
  on purpose (missing fields, a failing passport rule, a missing payment
  slip); a running "time saved" counter climbs to 5 h 00 m.
- **Guided** — a 6-step narrated walkthrough of the happy path.

## Running it

It is a single self-contained `index.html` — no build step. Open it in any
modern browser, or serve the folder over HTTP. React and the fonts load from
public CDNs, so an internet connection is needed on first load.

All names, IDs and organisations are fictional. Built by Wei Yun Neve Ning.
